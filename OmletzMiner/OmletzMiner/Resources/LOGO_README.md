Place the Hash'n'Omletz logo here as:

  logo.png   — 64×64 or larger PNG, will be scaled to fit
  omletz.ico — Windows icon file for the .exe taskbar/title bar

If logo.png is absent the app draws a fallback "H\O" text placeholder.
If omletz.ico is absent the project still builds (remove ApplicationIcon
from the .csproj if you don't have the .ico).
